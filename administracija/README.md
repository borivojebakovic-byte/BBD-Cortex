# Administracija

Korporativni dokumenti BBD Engineering-a: statut, organizaciona struktura, rešenja, elaborati i slično.

Svaki dokument je jedan `.md` fajl u ovom folderu (po potrebi u podfolderima po vrsti dokumenta). Ovaj README se ne prikazuje u aplikaciji; folder je u drvetu i na naslovnoj strani vidljiv i dok je prazan.
