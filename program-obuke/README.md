# Program obuke

Poglavlja internog dokumenta „Program obuke pripravnika” (BBD Engineering, Rev_00, april 2021), jedno poglavlje po folderu `NN-slug/` (npr. `02-cad-standard/`), sa slikama poglavlja u njegovom `media/` podfolderu.

Novo poglavlje = novi numerisani folder ovde; `cortex-app/build.js` ga sam uključuje i sortira po broju poglavlja.
